Clipx 0.1.0, build 1, is the first public Direct build for macOS 14 or later. It includes Apple Silicon and Intel binaries and a portable FFmpeg helper; Homebrew is not required to run it.

- Organize footage with watched folders, tags, ratings, projects, and full-text search.
- Mark clip ranges and export Reels, TikTok, YouTube Shorts, Instagram feed, YouTube 1080p, or YouTube 4K video.
- Export FCPXML and Obsidian sidecars, and use the Remote browser and Stint review integration.
- Receive updates through Clipx's signed Sparkle feed.

Download Clipx-0.1.0-1.zip, extract it, and move Clipx.app to Applications. The release also includes SHA256SUMS and the exact FFmpeg/x264 source archives, build script, and notices for the bundled helper.

Verification: the Mac Studio independently verified the MacBook's Developer ID signatures and checked that the app's code and resources match the original build. Software and VideoToolbox exports passed with the signed helper on Apple Silicon. Earlier checks covered all six export presets, the Remote browser, the HTTP server, FCPXML DTD validation, and an isolated Stint round trip.

Validation limits: Intel execution, native click automation, signed app launch, and an actual update installation remain unverified. Native testing was not retried while the build Mac was locked. Final Cut Pro import, a physical-phone session, and signed Mac App Store behavior remain separate checks.
